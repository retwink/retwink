## Why not GitHub

- It is owned by Microsoft, a proprietary platform that holds the code, the history and the community around it.
- Public code hosted here was used to train Copilot, a paid product, without asking authors and without honouring copyleft or attribution terms.
- GitHub kept a contract with US Immigration and Customs Enforcement in 2019 despite protests from its own staff.
- Git is decentralised; one company sitting in the middle of almost every project undoes that.

The Software Freedom Conservancy makes the full case: [Give Up GitHub](https://sfconservancy.org/GiveUpGitHub/).
